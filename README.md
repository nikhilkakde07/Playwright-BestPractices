## 🔄 Automated Workflow

Every successful GitHub Actions execution automatically:

✅ Executes Playwright Test Suite

✅ Generates Playwright Native Report

✅ Generates HTML Reporter

✅ Generates Allure Report

✅ Publishes Reports to GitHub Pages

✅ Updates Latest Execution Results
